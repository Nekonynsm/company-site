## ブラウザで index.html を開く手順

ビルドやサーバーは不要です。ファイルを直接ブラウザで開けば表示できます。

### 方法1：ファイルをダブルクリックする

1. エクスプローラーでこのフォルダ（`company-site`）を開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

別のブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」から選んでください。

### 方法2：ブラウザにドラッグ＆ドロップする

1. Chrome、Edge、Firefox などのブラウザを起動します。
2. `index.html` をブラウザのウィンドウにドラッグ＆ドロップします。

### 方法3：コマンドで開く

このフォルダで次のコマンドを実行します。

```powershell
# Windows（PowerShell）
start index.html
```

```bash
# macOS
open index.html

# Linux
xdg-open index.html
```

> **補足**：フォントは Google Fonts から読み込んでいます。インターネットに接続していない場合は、代わりの標準フォントで表示されます。
